## Issues found and fixed during the task

- The build failed until `README.md` existed, because `pyproject.toml` references it.
- `mypy --strict` rejected tests that patched attributes through `openharnx.doctor`. Fixed by using string patch targets.
- The first negative checks failed at the format stage, before the layer contracts ran. They were rerun with `lint-imports` directly to prove the contracts themselves detect violations.
- The TypeScript spike's first test run failed because Node 24's test runner does not accept a bare directory. This was a spike script error, not a language finding.

## Limitations

- There is no product functionality. T02 establishes the foundation only.
- Tested on macOS only; the supported-environment matrix is not declared yet.
- No CI and no remote repository.
- Two MPL-2.0 tools are present (`hypothesis`, `pathspec`); acceptance depends on ADR-0002 clause 3.
