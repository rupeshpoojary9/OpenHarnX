## The cheat demo (done, RC-16)

- `examples/cheat-demo/demo.py` replays, with no model and no network, a coding agent gaming its tests. Task: add percentage coupons to a shop's `order_total`. The agent's change breaks fixed coupons; it rewrites `test_fixed_coupon` to the new behaviour, skips `test_coupon_never_makes_total_negative` as obsolete and says "All tests pass". Plain pytest agrees (3 passed, 1 skipped). `ohx verify` against the suite locked with `ohx init --lock-tests` is BLOCKED, naming both tests and the skip. The genuine change is READY.
- Scripted rather than live so anyone can run it for free and get the same result. The demo checks its own verdicts and exits 1 if one differs. A live run with a real agent is recorded in T80.
