## Why

OpenHarnX's own verification of the T96 record took 637 seconds, 497 of them in the advisory mutation check. All ten mutants were in `docs/tasks/T96-examples/make_examples.py`, which no acceptance test imports, so none of them could have failed a test. A coding agent in a repair loop pays that on every round.

## Changed

- Mutants are made only in changed files that the acceptance tests imported, when every acceptance run recorded its imports (T90c's plugin, recorded per check since T96). Without that record (code outside a package, other test runners) nothing is filtered, as before.
- No mutant starts once the acceptance tests' own run time would take the check past its budget: 120 seconds, or `mutation_budget_s` in `ohx.toml`. The value is carried into the contract and must be a positive number.
- The note names the changed files that were not mutated and says how many mutants did not run and why. If none ran, the check is unavailable with that reason.
- The check stays advisory. Readiness and exit codes are unchanged.

The previous verifier's mutation check, run on T97, found a gap in T97's own tests: changing `and` to `or` in the import filter went unnoticed, because no test covered a run without import records. That test was added (`test_without_import_records_every_changed_file_is_still_mutated`). Two survivors remain and are accepted: the default value `120` changed to `121`, and `>` changed to `>=` on a measured time.

## Validation

- `tests/test_mutation_budget.py`, 8 tests: files no acceptance test imported are not mutated; only such files changed runs no mutant and costs no acceptance run; no mutant starts past the budget and the note says so; a budget below one acceptance run runs nothing; the budget is written into the contract; a budget that is not a positive number is refused; small projects keep every mutant under the default; without import records every changed file is still mutated.
- `./scripts/check.sh`: 523 passed, 14 skipped.

## Limitations

- "Imported" is a module load, not proof that the changed lines ran; a file that was imported but whose changed lines never ran is still mutated and shows as not exercised.
- The budget check uses the acceptance tests' run time from this verification as the cost of one mutant; a mutant that makes the tests hang can still take until the obligation's timeout.
- With a slow acceptance suite the default budget runs few mutants (two for OpenHarnX's own 50-second acceptance files). The note says how many did not run; raise `mutation_budget_s` when the strength of the tests matters more than the time.
