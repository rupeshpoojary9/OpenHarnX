## Why

0.1.x supports macOS locally and Linux in CI. Most CI runs on Linux, so a developer on Linux should get the same local verification. Linux had only been run as a CI runner or through `ci/linux/check.sh`, which runs the test suite and a gate, never the steps a user takes.

## What was run

`ci/linux/local_trial.sh`, in the `ohx-linux` image (Debian 13, arm64, kernel 6.10 under Docker Desktop, Python 3.12.14, Node 22, srt 0.0.77, bubblewrap, socat, ripgrep), as a non-root user: install `ohx` as a uv tool, `ohx doctor`, the cheat demo with `--sandbox srt`, then `ohx init --lock-tests` and `ohx verify --sandbox srt` on OpenHarnX's own tree. Also `ci/linux/check.sh` (the whole suite with the real sandbox).

## Findings, all fixed

| Finding | Cause | Fix |
|---|---|---|
| `test_the_report_names_the_folders_it_fingerprinted` failed, and so OpenHarnX's own verify was BLOCKED | Python's `venv` on 64-bit Linux adds `lib64 -> lib`. The fingerprint walks a folder reached through two names once (T100) and kept the `lib64` name, so the report named `venv/lib64/.../site-packages`. The same files were fingerprinted; only the name was an alias | The report shows each folder by its real path. The fingerprint keeps the walked names, so fingerprints already recorded still match |
| `ci/linux/gate_probe.py` said FAILED | The probe still expected READY for a gate with no acceptance tests; since the owner decision of 2026-10-04 that is NO REGRESSIONS, which the gate gave. Nothing runs the probe automatically, so it had gone stale | The probe expects NO REGRESSIONS |
| `ohx doctor` showed `srt: 1.0.0` | srt 0.0.77 prints `1.0.0` for `--version` (on macOS too) | Doctor reads the version from the npm package `srt` is linked from, and falls back to `--version` |

## Not covered

A physical Linux machine, x86_64, and Ubuntu 24.04's default AppArmor restriction on user namespaces (the container runs with `--security-opt` options a normal machine does not need; `docs/troubleshooting.md` has the Ubuntu setting). Until one of those is recorded, Linux outside CI stays experimental in the README and RC-27 stays not met.
