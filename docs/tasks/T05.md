## Delivered

- Threat model covering assets, roles, trust boundaries, 16 threats with M1 status, operational requirements and residual risks.
- A bypass suite with **positive controls**: every attack runs first without the sandbox, where it must succeed, then inside it. An attack that also fails without the sandbox is reported as invalid instead of prevented.

## Bypass results

Command: `uv run python spikes/boundary/bypass.py <srt> <scratch>`.

| ID | Attack | Outcome |
|---|---|---|
| B01 | Shell append to protected file | prevented |
| B02 | Delete protected file | prevented |
| B03 | Rename protected directory, then write | prevented |
| B04 | Symlink to protected file | prevented |
| B05 | Symlink to evidence store | prevented |
| B06 | Hard link to protected file | prevented |
| B07 | Write outside the allowlist | prevented |
| B08 | Background process outliving the command | prevented |
| B09 | launchd job outside the sandbox | prevented |
| B10 | AppleScript `do shell script` | prevented |
| B11 | Python `os.open` write | prevented |
| B12 | Verifier appends to candidate | prevented |
| B12b | Verifier creates a file in the candidate | prevented |
| B13 | Read `~/.ssh` | prevented |
| B14 | HTTPS egress | prevented |
| B15 | Raw TCP to an IP address | prevented |
| B16 | Secret in environment variable | **escaped**; prevented once launched with an environment allowlist |

B01 to B12b ran with automatic positive controls. B13 to B15 were confirmed manually: `~/.ssh` was readable, HTTPS succeeded and raw TCP connected, all outside the sandbox.

## Issues found in the harness and fixed

- The first version of B12b reset the scratch area before checking, so it could not fail. Fixed.
- The first version had no positive controls. Added, so every "prevented" result is meaningful.
- The B16 mitigation check first failed because `srt` could not create its Unix socket under a long `TMPDIR`. This became operational requirement 2 in the threat model.

## Limitations

- macOS only. Known techniques only; not an adversarial red-team.
- Agent-profile allowlist breadth and prompt-injection behavior are recorded as residual risks.
