<Callout type="note" title="Release 0.1.0 installs from GitHub">
0.1.0 is installed from its signed git tag. Publishing to PyPI (`uv tool install openharnx`) is prepared on `main` for the next release and is not available yet.
</Callout>

## Install

```bash
# OpenHarnX, pinned to the 0.1.0 release
uv tool install git+https://github.com/rupeshpoojary9/OpenHarnX@v0.1.0

# srt, the sandbox every check runs in (needs Node 20 or later)
npm install -g @anthropic-ai/sandbox-runtime@0.0.77

# Check the environment
ohx doctor
ohx --version
```

`ohx doctor` checks Python, git and the platform:

```text
ok    python: 3.12.7 (requires >= 3.12)
ok    git: git version 2.39.5 (Apple Git-154) (/usr/bin/git)
ok    platform: Darwin 25.5.0 arm64
```

It does not check `srt` in 0.1.0. If `srt` is missing, `ohx verify --sandbox srt` stops with a usage error that says so.

## Pin by commit where it matters

A tag can be moved; a commit cannot. In CI, or anywhere you need to be sure which verifier ran, install by the commit the release notes name:

```bash
uv tool install git+https://github.com/rupeshpoojary9/OpenHarnX@01626665a341812ded02c0559f5428c2e71d5ef1
```

`git ls-remote https://github.com/rupeshpoojary9/OpenHarnX v0.1.0` shows which commit the tag points to.

## Upgrade or remove

```bash
uv tool install --force git+https://github.com/rupeshpoojary9/OpenHarnX@<tag>
uv tool uninstall openharnx
```

The evidence store lives in `~/.openharnx` (or wherever `OHX_HOME` points). Uninstalling does not remove it.
