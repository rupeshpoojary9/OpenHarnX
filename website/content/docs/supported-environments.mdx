The release boundary is the repository's [release criteria](/docs/reference/release-criteria). Outside it, OpenHarnX makes no claim of protection.

## Supported in 0.1.0

| | Supported |
|---|---|
| Projects | Python, tested with pytest |
| Local verification | macOS on Apple silicon (arm64) |
| CI gate | Linux runners. GitHub-hosted `ubuntu-24.04` is tested; GitLab CI and Jenkins examples are provided |
| Sandbox | `srt` from `@anthropic-ai/sandbox-runtime` 0.0.77 |
| Coding agents | Any, through `ohx verify` or the CI gate. Claude Code has a built-in Stop hook |

## Prerequisites

- **Python 3.12 or newer.** `ohx doctor` checks it.
- **[uv](https://docs.astral.sh/uv/)**, to install the `ohx` command.
- **git.** The project must be a git repository with at least one commit.
- **Node 20 or later**, for `srt`, the sandbox the checks run in.
- **A pytest suite in `tests/`** at the repository root. That folder is what `ohx init --lock-tests` and the CI gate lock.
- **An interpreter with your test dependencies.** Checks run with `python` from `ohx.toml`, else the project's `.venv` or `venv`, else the active virtual environment.

For the CI gate the runner also needs bubblewrap, socat and ripgrep; the GitHub Action installs them. See [GitHub Actions](/docs/ci/github-actions).

## Experimental

These work and are tested, but are outside the 0.1.0 boundary:

- TypeScript and JavaScript projects (Vitest, Jest, `node --test`), with `environment = "npm"` protecting `node_modules` in CI.
- Go projects (`go test`).
- The advisory mutation check.
- `ohx bug`, which drives a coding agent through one bug fix.
- `ohx trace`, requirement coverage.

Details in [supported and experimental](/docs/reference/supported-and-experimental).

## Not supported

Linux outside CI, Windows, pnpm and Yarn lockfiles, Playwright, and more than one agent at a time.
